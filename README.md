# Telegram Multi-Service Account & Cookie Checker

100+ services · Account mode · Cookie mode · Bulk .txt support

## Features
- 100+ services (streaming, music, gaming, social, shopping, VPN, tools…)
- Account mode (`email:pass`)
- Cookie mode
- Paste lines or upload `.txt`
- Hits / Custom / Fails
- Stats + service list

## Commands / Buttons
- 🔍 Check Accounts
- 🍪 Check Cookies
- 📋 Services
- 📊 Stats
- ℹ️ Help

## Deploy (Railway)
1. Push this folder
2. Set `BOT_TOKEN` (or it uses the one already in code)
3. Deploy as worker
4. Talk to the bot on Telegram

## Note
Checker logic is currently a placeholder (hash-based demo hits).  
Swap `check_account` / `check_cookie` with real endpoints when ready.
